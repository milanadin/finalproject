# Описание
Веб-приложение для управления задачами с поддержкой правил повторения.
Позволяет добавлять, редактировать, удалять задачи и отмечать их выполненными.

## Запуск локально
1. Убедитесь что установлен Go
2. Склонируйте репозиторий
3. Запустите сервер:
go run main.go
4. Откройте в браузере: http://localhost:7540

База данных создаётся автоматически в файле `scheduler.db`.

## Запуск тестов
1. Запустите сервер: `go run main.go`
2. В файле `tests/settings.go` убедитесь что указан правильный адрес сервера
3. В отдельном терминале запустите:
go test ./tests/...
